# Kishori Product - Multi-Page Boutique Website

A professional, fully-functional multi-page website for the Kishori Product women's saree boutique.

## Pages

1. **index.html** - Home page with featured collections
2. **collections.html** - Organized collections (Bridal, Festive, Everyday)
3. **products.html** - Complete shop with all products
4. **about.html** - About the brand and mission
5. **contact.html** - Contact form and information
6. **styles.css** - Unified styling for all pages

## Features

- ✓ Responsive design for all devices
- ✓ Professional navigation
- ✓ Product grids and filtering
- ✓ Contact forms
- ✓ SEO-friendly structure
- ✓ Clean, modern aesthetic
- ✓ WhatsApp integration

## How to Use

1. Upload all files to your web hosting
2. Update contact information (phone, email, address)
3. Replace product images with your own
4. Customize colors in styles.css
5. Add WhatsApp business integration

## Customization

- Colors: Update CSS variables in styles.css
- Fonts: Cormorant Garamond (serif) for headings, Inter (sans-serif) for body
- Images: Replace unsplash URLs with your product photos

# Kishori Product - React/Next.js Version

A modern, fully-featured React and Next.js implementation of the Kishori Product boutique website.

## Features

✨ **Modern Stack**
- React 18 with Next.js 14
- Tailwind CSS for styling
- Server-side rendering (SSR)
- Optimized performance
- WhatsApp integration

📄 **Pages**
- Home with hero section
- Collections page
- Shop page with all products
- About page
- Contact page with form

## Installation

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

## Build for Production

```bash
npm run build
npm start
```

## Customization

- Colors in `tailwind.config.js`
- Product data in component files
- Contact information throughout
- Replace images with your own
